# claudeis.gay

Static parody site for `claudeis.gay`.

## Deploy

Push this folder to GitHub, import the repo in Vercel, and use the default static settings. The root `index.html` is the entry point, with no build step required.

## Files

- `index.html` - page markup
- `styles.css` - responsive visual design
- `script.js` - interactive mood console and animated background
- `assets/favicon.svg` - favicon
